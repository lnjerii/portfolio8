# Wanjiru Lucy Njeri - Portfolio

A modern, glassmorphism-style personal portfolio website for Wanjiru Lucy Njeri, an Information Technology student at Kabarak University.

## Features

- Glassmorphism UI with frosted glass effects
- Responsive design (desktop, tablet, mobile)
- Smooth animations and hover effects
- Light/Dark theme toggle
- Sections: Hero, About, Skills, Projects, Certifications, Contact

## Technologies Used

- HTML5
- CSS3 (with glassmorphism effects)
- JavaScript (ES6+)
- Font Awesome for icons

## Local Development

1. Clone or download the repository
2. Open `index.html` in your browser, or
3. Run a local server:

   ```bash
   python -m http.server 8000
   ```

   Then visit `http://localhost:8000`

## Hosting

### GitHub Pages

1. Create a new repository on GitHub
2. Push this code to the repository
3. Go to Settings > Pages
4. Select "Deploy from a branch" and choose `main` branch
5. Your site will be live at `https://yourusername.github.io/repository-name`

### Netlify

1. Go to [Netlify](https://netlify.com)
2. Drag and drop the project folder, or connect your GitHub repo
3. Deploy automatically

## Customization

- Edit `index.html` for content changes
- Modify `styles.css` for styling
- Update `script.js` for functionality
